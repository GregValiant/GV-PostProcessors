# GregValiant's PostProcessors and Plugins for Cura and Prusa/Orca/BambuStudio/CrealityPrint

As I have learned more about 3D Printing I realized that sometimes a print could use some specific type of help.  Some of those helpers (like Cura's PauseAtHeight) already existed, but they often didn't really provide what I wanted.  Others didn't exist at all.  So I started makeing changes to the built in scripts of Cura, and then added some of my own.
Some of my scripts are now included with Cura.  Others are definite "niche" things and will never be submitted.  I have put the scripts I've altered, written, butchered together here in one place.  
 
As I work on these I update the Git page.  The versions here should work as described for the particular slicer they were aimed at.  None of these scripts are "version specific".  All the Cura scripts should work with any of the Cura based slicers (but I don't debug in any of the forks except for SmartAvionics Master version).  That includes the Cura based versions of Creality Slicer.
The Slic3R clone slicers can all use the scripts that were written for them.  That includes Creality Print.  
Since I am a one-man-band there may be bugs that I did not catch.  Let me know if there are issues with the post processors.
